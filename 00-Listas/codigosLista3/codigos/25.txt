  a) O que é herança?
  -------------------
  Herança é quando uma classe (subclasse) "herda" os atributos e métodos
  de outra classe (superclasse). Isso evita repetição de código e cria
  uma relação do tipo "é um". Por exemplo: Aluno É UMA Pessoa.
  Em Java, usamos a palavra-chave 'extends':
 
      class Aluno extends Pessoa { ... }
 
  A subclasse pode usar tudo que a superclasse tem (exceto o que é private)
  e ainda acrescentar seus próprios atributos e métodos.
 
 
  b) Qual a diferença entre classe base e subclasse?
  ---------------------------------------------------
  Classe base (ou superclasse): é a classe "pai", mais genérica.
  Define os atributos e comportamentos comuns.
  Exemplo: Pessoa (tem nome e idade)
 
  Subclasse: é a classe "filha", mais específica.
  Herda da classe base e acrescenta suas próprias características.
  Exemplo: Aluno (herda nome e idade, e adiciona matricula e curso)
 
 
  c) O que é um array?
  ---------------------
  Array é uma estrutura de dados que armazena um conjunto de elementos
  do mesmo tipo, com tamanho fixo definido na criação. Cada elemento é
  acessado por um índice (começando em 0).
 
  Exemplo:
      int[] numeros = new int[5];   // cria array de 5 inteiros
      numeros[0] = 10;              // acessa a primeira posição
 
  O tamanho não pode ser alterado depois que o array é criado.
 
 
  d) O que é um ArrayList?
  -------------------------
  ArrayList é uma classe da biblioteca do Java (java.util) que funciona
  como um array dinâmico — o tamanho cresce ou diminui conforme você
  adiciona ou remove elementos. Ela já vem com vários métodos úteis
  como .add(), .remove(), .size(), .get(), .contains(), etc.
 
  Exemplo:
      ArrayList<String> nomes = new ArrayList<>();
      nomes.add("Ana");    // adiciona
      nomes.remove("Ana"); // remove
      nomes.size();        // quantidade atual
 
 
  e) Qual a principal diferença entre array e ArrayList?
  -------------------------------------------------------
  | Característica     | array             | ArrayList              |
  |--------------------|-------------------|------------------------|
  | Tamanho            | Fixo              | Dinâmico               |
  | Tipo               | Primitivo ou obj. | Só objetos (wrapper)   |
  | Acesso por índice  | vetor[i]          | lista.get(i)           |
  | Métodos utilitários| Não tem           | .add, .remove, .size   |
  | Desempenho         | Levemente mais rápido | Um pouco mais lento |
 
  Em resumo: array é mais simples e eficiente, mas rígido.
  ArrayList é mais flexível e fácil de usar, mas exige um pouco mais.
 
 
  f) Por que uma ArrayList<Pessoa> pode armazenar Aluno e Professor?
  -------------------------------------------------------------------
  Porque Aluno e Professor são subclasses de Pessoa — ou seja, eles
  herdam de Pessoa. Em POO, isso se chama polimorfismo: um objeto
  do tipo Aluno também pode ser tratado como Pessoa.
 
  Então quando declaramos ArrayList<Pessoa>, estamos dizendo:
  "essa lista guarda objetos do tipo Pessoa OU qualquer subclasse dela".
 
  Exemplo:
      ArrayList<Pessoa> lista = new ArrayList<>();
      lista.add(new Aluno(...));     // funciona! Aluno é Pessoa
      lista.add(new Professor(...)); // funciona! Professor é Pessoa
 
 Na hora de exibir, se as subclasses sobrescrevem o método exibir()
 com @Override, o Java vai chamar a versão correta de cada objeto.
 Isso é polimorfismo em ação.
