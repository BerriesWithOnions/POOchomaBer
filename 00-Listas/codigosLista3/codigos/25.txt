  a) O que é herança?
 
 Herança é uma relação entre duas classes, na qual uma classe "é uma" variação da outra, em relação de subordinação.
 Por exemplo, um Aluno é uma Pessoa (mas nem toda Pessoa é um Aluno), e por isso o aluno tem alguns atributos comuns
 a todas as pessoas (como exemplo de um código deste projeto, temos o aluno que extends pessoa e via super herda os 
 atributos nome e idade da superclasse pessoa). O que é Superclasse? Basicamente superclasse é a classe que possui os 
 atributos que serão herdados pela subclasse.
 
  b) Qual a diferença entre classe base e subclasse?

Classe base é a superclasse, é a portadora dos atributos que serão herdados pelas suas filhas. ex.: Pessoa.
Sublcasse é a filha da classe base, é quem herda os atributos. ex.: Aluno.
 
 
  c) O que é um array?

Array é uma estrutura de dados que armazena informações do mesmo tipo, e que também tem um tamanho fixo predefinido. 
Poderiamos dizer que um Array é uma lista.
Usamos índices para nos referir aos elementos da lista. Por exemplo, digamos que eu tenha um Array 
pessoas[3] = [Leandro, Robson, Ana]
de pessoas. A pessoas[0] = Leandro, pessoas[1] = Robson e pessoas[2] = Ana.

 
 
  d) O que é um ArrayList?

ArrayList é uma classe de uma biblioteca java (java.util) que funciona como um Array dinâmico (ao invés
de tamanho predefinido, podemos adicionar ou remover itens do ArrayList). A classe vem com alguns métodos 
úteis já implementados, como add() - adiciona itens na lista, remove() - remove itens da lista, 
isEmpty() - retorna se a lista está vazia, get() - retorna o item em um determinado indice da lista, 
set() - altera o item que está localizado em dada posição da lista.
 
 
  e) Qual a principal diferença entre array e ArrayList?

Array é mais simples, eficiente, porém é mais rígido (não pode ficar mexendo, tem tamanho fixo e precisa ser reescrito)
    Tamanho fixo, aceita tipos primitivos ou objetos instanciados, o acesso é por indexação (pessoas[1]), não tem métodos utilitários
    e é mais rápido para ser executado.


ArrayList é mais dinâmico, mas é mais exigente e lento para rodar.
    Tamanho dinâmico, só aceita objetos instanciados, o acesso ao índice é feito pelo método get (pessoas.get(1)), possui métodos
    utilitários e é mais lento para ser executado.
 
 
  f) Por que uma ArrayList<Pessoa> pode armazenar Aluno e Professor?
 
 Em POO existe um conceito chamado polimorfismo. Basicamente subclasses de alguma superclasse podem ser tratadas como um objeto daquela
 superclasse. No caso analisado, Aluno e Professor são são subclasses de Pessoa, e portanto podem ser tratados como Pessoa. 
 Então quando criamos ArrayList<Pessoa>, dizemos para o java que a lista é de objetos Pessoa ou qualquer subclasse de Pessoa.
