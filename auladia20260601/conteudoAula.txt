CLIENTE/SERVIDOR é via de mão única. Perguntas (requests) são exclusivas do cliente. 
Respostas são exclusivas do servidor.
A implementação orientada a objetos se encontra no servidor.

SpringBoot -> é um FRAMEWORK
Quando estamos usando java, se queriamos ler algo do terminal, usávamos o io (assim como em python). São
comandos pré-programados. São bibliotecas
Framework - é como uma caixa de ferramentas. Usamos uma caixa com as ferramentas que aprendemos a usar. Agora que
sabemos java, usaremos o SpringBoot. Ao invés de usar uma chave de fenda, usaremos uma parafusadeira. Usamos só
a lógica e a OO. Framework oferece uma linha de aprendizagem mais bem desenvolvida. 

Link do SpringBoot: https://spring.io/projects/spring-boot
